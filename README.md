# ЛИНИЯ — демо сайта клиники

Демонстрационный сайт вымышленной клиники эстетической косметологии: тёмная современная подача с 3D-иллюстрациями, анимациями GSAP, картой лица на портрете, планом визита и записью. Одна страница, статическая сборка, без бэкенда. Клиника, врачи, цены и тексты вымышлены. В `<head>` стоит `noindex,nofollow`.

## Запуск

```bash
npm install
npm run dev        # разработка, http://localhost:5173
npm run build      # проверка типов и сборка в dist/
npm run preview    # просмотр сборки
node scripts/render-tiles.mjs   # перерисовать плитки галереи (нужен запущенный npm run dev и Playwright)
node scripts/shoot.mjs http://localhost:5173/ метка   # скриншоты 390, 768, 1440 px
```

## Что заменить под реальную клинику

| Что | Где |
|---|---|
| Название, адрес, часы, мессенджеры, координаты, консультация | `src/config.ts` |
| Процедуры, цены, длительность, курсы | `src/data/procedures.json` |
| Услуги в списке, готовые курсы | `src/data/services.json`, `src/data/plans.json` |
| Статьи журнала, словарь | `src/data/journal.json`, `src/data/glossary.json` |
| Портрет героини и карта лица | `src/assets/img/girl.webp`, подписи и точки в `src/components/face-map.ts` |
| Плитки галереи | `src/assets/gallery/*.jpg` (генерируются из 3D-сцены, см. `src/three/tiles.ts`) |
| Палитра, шрифты, отступы | `src/styles/tokens.css` |

Все тексты журнала и словаря помечены `"demo": true` и предназначены к замене текстом клиники и проверке врачом.

## Внешние запросы

Единственный внешний запрос: погода в блоке «Наблюдение дня» (Open-Meteo, таймаут 4 с, при сбое показывается пример). Open-Meteo бесплатен для некоммерческого использования; для рабочего сайта нужен платный тариф или другой источник.

## Отличия от исходного ТЗ

По просьбе заказчика направление изменено на тёмное современное: Three.js и GSAP (оба с открытыми лицензиями) используются для 3D-объектов и анимаций, портрет героини предоставлен заказчиком. Чанки `fx` (Three.js) и `motion` (GSAP) грузятся отдельно после первой отрисовки.
